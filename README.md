# Digital Marketing Performance Dashboard

## Project Overview

This project analyses digital marketing campaign performance using Tableau and Excel. The dashboard provides insights into campaign effectiveness, customer engagement and key marketing metrics to support data-driven decision-making.

---

## Objectives

- Evaluate overall campaign performance.
- Analyse marketing KPIs.
- Compare channel performance.
- Identify trends and opportunities for optimization.
- Support strategic marketing decisions.

---

## Tools Used

- Tableau
- Excel

---

## Dashboard Features

- KPI Cards
- Campaign Performance Overview
- Channel-wise Analysis
- Clicks & Impressions Analysis
- Conversion Rate Analysis
- Cost Analysis
- ROI Analysis
- Interactive Filters

---

## Key Insights

- Analysed campaign performance across multiple marketing channels.
- Compared clicks, impressions, conversions and ROI.
- Identified high-performing marketing campaigns.
- Built an interactive Tableau dashboard with KPIs and filters.
- Generated insights to improve marketing strategies.
